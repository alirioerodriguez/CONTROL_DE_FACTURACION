**Asunto:** Integración honorapp + Facturitas para profesionales de la salud

Hola, equipo de Facturitas:

Soy Alirio, el creador de **honorapp**, una app para que profesionales que atienden pacientes (psicólogas, nutricionistas, kinesiólogos, etc.) lleven sus cobros: sesiones, pagos, recordatorios y el reporte para su contadora. La mayoría son monotributistas y facturan con Factura C.

honorapp ya arma la lista de pagos que falta facturar con los datos del receptor, el período y el importe. Hoy esos datos se pueden bajar en una planilla para su Facturación Masiva, pero nos gustaría ir más lejos, con algo parecido a lo que hacen con RappiBoy:

- honorapp les manda los pagos para facturar de cada profesional que lo pida.
- Facturitas le confirma por WhatsApp y emite la factura.
- Nos devuelven el número de comprobante para marcar el pago como facturado.

Nos interesa conversar sobre:
1. Si tienen (o planean) una API o un acuerdo de integración para apps como la nuestra.
2. Condiciones comerciales: precio especial para usuarias de honorapp, comisión por referido o un plan conjunto.
3. El formato oficial de la planilla de Facturación Masiva y del resumen de lo emitido, para que la integración por planilla quede exacta mientras tanto.
