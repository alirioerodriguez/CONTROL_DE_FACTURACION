# Mails de la app (Supabase → Authentication → Emails)

Textos en castellano para los mails que manda Supabase. Ya están cargados en Supabase (SMTP propio: honorapp.ar@gmail.com).
Para cambiarlos: copiar el asunto y el HTML de cada archivo en la plantilla correspondiente del panel.

| Archivo | Asunto |
|---|---|
| confirmar-cuenta.html | Confirmá tu cuenta en honorapp |
| recuperar-clave.html | Recuperá tu contraseña de honorapp |
| link-de-ingreso.html | Tu link para ingresar a honorapp |
| cambio-de-mail.html | Confirmá el cambio de mail en honorapp |
| invitacion.html | Te invitaron a honorapp |
| reautenticacion.html | Tu código de verificación de honorapp |
| contrasena-cambiada.html | Cambiaste tu contraseña de honorapp (aviso de seguridad, activado) |
| mail-cambiado.html | Cambió el mail de tu cuenta de honorapp (aviso de seguridad, activado) |

Plantilla de Supabase ↔ archivo: Confirm sign up → confirmar-cuenta · Reset password → recuperar-clave · Magic link → link-de-ingreso · Change email address → cambio-de-mail · Invite user → invitacion · Reauthentication → reautenticacion · Security: Password changed → contrasena-cambiada · Email address changed → mail-cambiado.
